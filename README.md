# 🌍 Adeus, mundo! ♡

**Seu mundo começa com um sonho.**

> Para quem ainda não foi, para quem está indo e para quem nunca deixou de sonhar.

## 💗 Sobre o projeto

O **Adeus, mundo!** é uma plataforma de planejamento e compartilhamento de viagens, inspirada na ideia de um diário pessoal de sonhos.

O projeto nasceu do desejo de criar guias de viagens cuidadosamente pesquisados, permitindo que pessoas que ainda não tiveram a oportunidade de viajar possam conhecer destinos, organizar suas ideias e construir seus próprios roteiros.

Mais do que um planejador, o Adeus, mundo! pretende ser um espaço onde sonhos de viagem podem ser registrados, desenvolvidos e compartilhados.

## 🌸 Estilos de viagem

O aplicativo trabalha com três categorias:

**🌿 Econômica:** viagens acessíveis, focadas em economia e custo-benefício.

**🌸 Executiva:** equilíbrio entre conforto, praticidade e orçamento.

**💎 Premium:** experiências exclusivas e viagens com maior nível de conforto.

Cada pessoa poderá escolher o estilo que melhor representa seus objetivos e possibilidades.

## 💻 Como executar

É necessário ter o Node.js e o npm instalados.

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. No terminal, entre na pasta `FrontEnd`:

```bash
cd FrontEnd
```

4. Instale as dependências:

```bash
npm install
```

5. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

6. Abra no navegador o endereço local informado pelo Vite.
